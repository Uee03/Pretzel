# Changelog

All notable changes to this package are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the package uses [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-10-27

First published release. Version 0.1.0 was internal and never tagged.

### Added

- LitMotion ease mapping, UniTask `ApiClient` calls and R3 observables for UI Toolkit and `ApiClient`, each compiled only when its library is installed.
- VContainer composition root: `PretzelLifetimeScope`, `ScriptableInstaller`, `MonoInstaller`, PlayMode tests, and a guide in `Documentation~/VContainer.md`. The VContainer tab of Pretzel Setup generates and wires it.
