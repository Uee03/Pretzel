# Changelog

All notable changes to this package are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the package uses [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-10-27

First published release. Version 0.1.0 was internal and never tagged.

### Added

- Script templates for a MonoBehaviour, a UI controller and a singleton.
- **Assets > Create > Pretzel > UI Toolkit Theme**: a runtime theme (`.tss`) with palette, spacing and typography variables and styles for built-in controls and Pretzel toasts.
